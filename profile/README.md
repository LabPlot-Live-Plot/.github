## What Is LabPlot

LabPlot is a scientific plotting and analysis application with a worksheet metaphor. People who already capture columns from sensors, CSV dumps, or classroom experiments open LabPlot scientific worksheet to keep the table and the figure in one file. LabPlot live plot is for feeds that still change. LabPlot data fit is the curve on those points. LabPlot analysis sheet is the project you save.

Compared with QtiPlot, the emphasis is a structured notebook of elements rather than a single Origin-like window. Compared with JASP, there is no APA Bayesian table as the main product. Compared with SciDAVis, LabPlot leans harder into worksheets and live data.

Plot series you captured or were given for a lab you administer. Keep the project with the instrument notes. Do not stream someone else’s private sensor without permission.

## Starting with LabPlot

Prerequisites: A PC you administer and a series or live source you are allowed to plot.

1. **Prepare:** Point at the CSV or device path from the capture you already run.
2. **Configure:** Create LabPlot scientific worksheet and place a spreadsheet element for those columns.
3. **Test:** Plot a known channel as LabPlot live plot or a static graph and match a hand value.
4. **Refine:** Add LabPlot data fit and annotations the report actually needs.
5. **Apply:** Grow LabPlot analysis sheet with the remaining channels of that experiment.
6. **Maintain:** Save with the run ID, and disconnect feeds you no longer own.

## Best Uses

- **Classroom Sensors You Administer:** LabPlot live plot on a logger the lab already has.
- **CSV From A Bench You Ran:** LabPlot scientific worksheet instead of five Excel charts.
- **Fit For A Lab Report You Write:** LabPlot data fit with residuals you can show.
- **Not A Medical ROC Desk:** Use MedCalc for diagnostic curves.
- **Not A DOE Plant Study:** Use Statgraphics Centurion.
- **One Run Per Worksheet When That Keeps Notes Honest:** Mixing days hides LabPlot analysis sheet history.
- **CAS Only If You Already Use It:** Do not turn a simple plot into an unused algebra pane.
- **Export The Figure The Course Asked:** Vector or PNG from the worksheet you keep.
- **Channel Names From The Logger:** LabPlot live plot should use the labels the instrument already wrote.
- **Residual Plot Beside The Fit:** LabPlot data fit is incomplete without it on LabPlot analysis sheet.
- **CSV Encoding You Actually Exported:** Commas versus tabs on a series you captured.
- **One Sensor Family Per Worksheet:** Mixing unrelated benches hides LabPlot scientific worksheet notes.
- **Disconnect Overnight Feeds:** A live plot you no longer watch still writes if the path stays open.
- **Backup Before A Demo:** Classroom projects you administer should survive a crashed session.
